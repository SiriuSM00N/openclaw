## 📝 测试题目（5 大类）

### 一、游戏系统设计（咔啦米核心场景）

**题目 1：设计一个 Roguelike 游戏的成长系统**
```
请设计一个 Roguelike 手游的成长系统，包括：
1. 局外成长（永久升级）
2. 局内成长（单局强化）
3. 两种成长的循环关系
4. 数值成长曲线的大致设计

要求：结构清晰，可直接用于策划文档
```

**评估维度：**
- 系统完整性
- 逻辑自洽性
- 可落地性
- 文档规范性

---

**题目 2：经济系统平衡分析**
```
一个手游有以下资源：
- 金币（基础货币）
- 钻石（付费货币）
- 体力（限制玩家进度）

请设计：
1. 三种资源的产出途径
2. 三种资源的消耗途径
3. 付费玩家 vs 免费玩家的平衡点
4. 防止经济通胀的机制
```

**评估维度：**
- 经济模型合理性
- 付费设计深度
- 长期运营考虑

---

### 二、代码能力

**题目 3：写一个数值模拟脚本**
```
用 Python 写一个函数，模拟角色成长曲线：
- 输入：角色等级（1-100）
- 输出：所需经验值
- 曲线类型：指数增长，但后期放缓
- 要求：可调整参数，有注释，可运行

额外要求：生成一张等级 - 经验曲线图
```

**评估维度：**
- 代码正确性
- 代码质量（注释、结构）
- 是否可直接运行
- 图表生成能力

---

**题目 4：代码 Debug**
```
下面这段代码有问题，请找出并修复：

def calculate_damage(base_damage, multiplier, enemy_defense):
    damage = base_damage * multiplier
    final_damage = damage - enemy_defense
    return final_damage

问题：当 enemy_defense 很高时，damage 可能变成负数
```

**评估维度：**
- 问题识别准确度
- 修复方案合理性
- 是否考虑边界情况

---

### 三、长文本理解

**题目 5：长文档总结**
```
（准备一份 5000+ 字的游戏设计文档或技术文章）

任务：
1. 总结核心观点（300 字以内）
2. 提取关键信息点（bullet list）
3. 指出可能的逻辑漏洞
4. 给出改进建议
```

**评估维度：**
- 理解准确度
- 总结精炼度
- 关键信息提取
- 批判性思考

---

### 四、日常对话/问问题

**题目 6：概念解释**
```
请用通俗易懂的方式解释：
1. 什么是"核心游戏循环"？
2. 什么是"付费点设计"？
3. 什么是"留存率"？

要求：给外行讲也能听懂，有例子
```

**评估维度：**
- 表达清晰度
- 例子恰当性
- 对话自然度

---

**题目 7：创意头脑风暴**
```
我们要设计一个创新的 Roguelike 玩法，
结合"卡牌构建"和"动作战斗"。

请给出 5 个创意方向，每个方向包括：
1. 核心玩法描述
2. 差异化亮点
3. 潜在风险
```

**评估维度：**
- 创意质量
- 可行性分析
- 思考深度

## ⏱️ 测试执行计划

### 方案 A：集中测试（推荐）
**时间：** 2-3 小时一次性完成
**方式：** 每个模型跑完所有题目
**优点：** 印象新鲜，对比直观
**缺点：** 一次性耗时较长

### 方案 B：分散测试
**时间：** 每天测 1-2 个模型，一周完成
**方式：** 利用碎片时间
**优点：** 不累
**缺点：** 对比感弱
