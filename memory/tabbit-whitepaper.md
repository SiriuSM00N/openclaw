## 🛠️ 核心功能

### 1. 对话（Chat）
- 针对当前网页提问/总结/分析
- 支持 @任意已打开的标签页
- 支持上传本地文件/图片
- 可切换不同模型

**白嫖场景：**
- 读文章 → 一键总结
- 多文档对比 → @多个标签页让 AI 整理表格
- 文件分析 → 上传 PDF/图片让 AI 解读

### 2. 妙招（Shortcuts）
三种类型：
- **提示词妙招**：保存常用 prompt，一键调用
- **脚本妙招**：自然语言描述，自动生成脚本
- **智能代理妙招**：自动化复杂任务

**白嫖场景：**
- 保存"微博文案生成"prompt → 输入 `/` 一键调用
- "把这个网页改成 QQ 空间风格" → 自动生成脚本
- "提取文章封面图" → 一键执行

### 3. 智能代理（Agent）
- 自动规划搜索策略
- 访问相关网站
- 筛选有效信息
- 整合分析数据
- 输出完整报告（带引用来源）

**白嫖场景：**
- "写一份 AI 视频生成产品分析报告"
- "调研国内最新主流 XX 产品"
- "帮我规划 XX 旅游路线"

### 4. 收藏（Smart Bookmarks）
- 不只保存 URL，还保存网页内容
- AI 自动生成摘要
- 语义搜索（即使标题里没有关键词）
- 右键收藏任意图片/文字片段
- 云同步

**白嫖场景：**
- 收藏文章 → AI 自动总结 → 以后搜索"翻译"能找到相关内容
- 右键收藏图表 → 自动保存 + 索引

### 5. 标签管理
- 垂直标签栏（纵向排列，显示完整标题）
- 智能分组（按内容自动归类）
- 标签组保存与恢复
- 云同步

## 💡 我们的白嫖策略

### 场景 1：研究/调研
```
1. 用 Tabbit 打开多个相关网页
2. 点击右上角 Chat
3. @所有标签页
4. 指令："从 XX 角度整理对比表格，附信息来源"
5. 切换不同模型对比结果（Kimi vs Qwen vs DeepSeek）
```

### 场景 2：写报告/文章
```
1. 创建"妙招"：保存常用 prompt 模板
2. 输入 `/` 调用妙招
3. 让 Agent 自动搜索整理资料
4. 输出带引用的报告
```

### 场景 3：学习/阅读
```
1. 打开长文章/论文
2. Chat → 总结核心观点
3. 收藏 → AI 生成摘要
4. 以后用语义搜索快速回顾
```

### 场景 4：多模型对比
```
1. 同一问题，切换不同模型提问
2. 对比回答质量
3. 找到最适合某类任务的模型
4. 以后固定用那个模型处理同类任务
```
