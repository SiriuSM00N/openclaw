## 💡 使用技巧

### 自动调度策略

```
if 任务包含 ["代码"、"写个"、"函数"、"脚本"]:
    → Qwen3-Coder-Plus
elif 任务包含 ["审查"、"找 bug"、"优化"]:
    → Kimi-K2.5
elif 任务包含 ["设计"、"架构"、"系统"]:
    → GLM-5
elif 任务包含 ["评估"、"创意"、"建议"]:
    → MiniMax-M2.5
elif 任务简单 (字数<100):
    → GLM-4.7
else:
    → Qwen3.5-Plus (默认)
```

### 节省额度技巧

1. **简单任务用 GLM-4.7** — 快且省
2. **长对话用 Qwen3.5-Plus** — 均衡
3. **关键任务用专用模型** — 保证质量
4. **避免频繁切换** — 减少心智负担

## 📝 测试结论

1. **没有全能模型** — 每个模型有明确优势场景
2. **Qwen3.5-Plus 是最佳默认** — 均衡、快速、自然
3. **专用任务用专用模型** — 代码用 Coder，设计用 GLM-5
4. **GLM-4.7 被低估** — 简单任务性价比极高
5. **MiniMax-M2.5 创意突出** — 评估/头脑风暴首选
