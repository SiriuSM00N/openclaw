# 模型对比测试 - 第1轮：系统设计

_测试日期：2026-03-10 | 测试题目：黄金矿工卡牌系统设计_

---

## 📋 测试说明

**题目：** 设计一个黄金矿工小游戏的增益卡牌系统

**要求：**
- 10-15 张增益卡牌
- 每张卡牌包括：名称、效果、稀有度、获取方式
- 简单数值规划（效果强度、持续时间）
- 分析哪些卡牌组合会比较有趣

**参测模型（6 个）：**
- Qwen3.5-Plus
- Qwen3-Coder-Plus
- Kimi-K2.5
- GLM-5
- GLM-4.7
- MiniMax-M2.5

| 9 | 钩子加速 | 钩子摆动速度提升 30%，持续 35 秒 |
| 10 | 磁铁效应 | 钩子自动吸附附近的物品，持续 25 秒 |
| 11 | 宝藏猎手 | 宝藏出现概率提升 300%，持续 30 秒 |
| 12 | 稳如泰山 | 钩子命中目标 100% 成功，持续 15 秒 |

3. 瞬间抓取 + 钩子加速 → 极大提升抓取频率
4. 时间静止 + 万能磁铁 → 安全环境下最大化收益
5. 石头变金 + 金光闪闪 → 废品变宝

**特点：** 简洁直接，组合分析清晰
