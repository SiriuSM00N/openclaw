## 🐛 Cron 系统问题记录

### 问题 1：钉钉推送失败（已修复）

**时间：** 2026-03-11 至 2026-03-12 凌晨

**现象：** 系统日志显示成功，但用户实际没收到

**根因：**
1. 钉钉连接器无限重启循环（health-monitor 与 channel 重启冲突）
2. Cron delivery 配置错误（announce vs direct）

**修复：**
- Gateway 重启重置钉钉连接器
- 禁用 health-monitor（`channelHealthCheckMinutes: 0`）

**状态：** ✅ 已修复，2026-03-12 早安资讯成功推送

---

### 问题 2：Cron 重复触发 Bug

**时间：** 2026-03-12 11:39-11:41

**现象：** 早安资讯任务被重复触发 4 次

**根因：** 任务状态卡在 `runningAtMs`，导致 Cron 调度器认为任务还在运行，不断重试

**临时修复：**
```bash
openclaw cron disable <jobId>
sleep 2
openclaw cron enable <jobId>
```

**状态：** 📝 已记录，等 OpenClaw 官方修复（isolated session bug #42632）

---

### 问题 3：每日 AI 新闻收集超时

**时间：** 2026-03-12 09:28
