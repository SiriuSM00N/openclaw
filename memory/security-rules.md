## 🔴 敏感信息模式

| 类型 | 正则模式 | 示例 | 风险等级 |
|------|----------|------|----------|
| **API Key** | `sk-[a-zA-Z0-9]{20,}` | sk-229050cc... | 🔴 高 |
| **API Key** | `AKIA[0-9A-Z]{16}` | AKIAIOSFODNN7... | 🔴 高 |
| **GitHub Token** | `ghp_[a-zA-Z0-9]{36}` | ghp_xxxx | 🔴 高 |
| **Slack Token** | `xoxb-[0-9a-z-]+` | xoxb-123... | 🔴 高 |
| **Bearer Token** | `Bearer\s+[a-zA-Z0-9_-]+` | Bearer xxx | 🔴 高 |
| **密码** | `password\s*[=:]\s*\S+` | password=123 | 🔴 高 |
| **Secret** | `SECRET[_A-Z]*\s*[=:]\s*\S+` | SECRET_KEY=xxx | 🔴 高 |
| **私钥** | `BEGIN.*PRIVATE KEY` | -----BEGIN RSA... | 🔴 高 |
| **邮箱** | `[a-z0-9._%+-]+@[a-z0-9.-]+\.[a-z]{2,}` | test@example.com | 🟡 中 |
| **手机号** | `1[3-9]\d{9}` | 13800138000 | 🟡 中 |
| **内网 IP** | `192\.168\.\d+\.\d+` | 192.168.1.1 | 🟡 中 |
| **本机路径** | `/Users/\w+/` | /Users/sirius/ | 🟢 低 |
| **环境变量** | `export\s+\w*KEY\w*\s*=` | export API_KEY= | 🟡 中 |
| **钉钉 ID** | `\d{15,}` | 333446632538210751 | 🟡 中 |

## ✅ 扫描流程

### 发布前检查

1. **扫描所有文件**
   - 读取待发布的所有文件内容
   - 逐行匹配敏感信息模式

2. **命中规则处理**
   - 🔴 高风险 → 强制阻止发布
   - 🟡 中风险 → 高亮标注 + 用户确认
   - 🟢 低风险 → 提示 + 可继续

3. **生成扫描报告**
   ```markdown
   ## 🔒 安全扫描结果
   
   **扫描文件：** 3 个
   **命中规则：** 2 条
   **风险等级：** 🟡 中
   
   **详情：**
   - memory/skills.md:15 → 发现 API Key（已脱敏）
   - scripts/config.py:8 → 发现本机路径
   
   **用户确认：** [ ] 我已检查，确认可以发布
   ```

4. **用户决策**
   - ✅ 确认 → 继续发布
   - ❌ 取消 → 停止发布，修复后重试

## 🛡️ 脱敏规则

**发现敏感信息后：**

| 类型 | 脱敏方式 | 示例 |
|------|----------|------|
| API Key | 保留前 8 位 + `****` + 后 4 位 | sk-2290****487a |
| Token | 完全隐藏 | `[REDACTED]` |
| 邮箱 | 保留域名 | `***@example.com` |
| 手机号 | 保留前 3 后 4 | `138****8000` |
| IP 地址 | 保留前两段 | `192.168.*.*` |
| 路径 | 替换为用户名 | `/Users/[USER]/...` |
