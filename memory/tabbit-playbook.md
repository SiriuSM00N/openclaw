## 2. 执行流程

### 2.1 单次任务标准流程

```
┌──────────────┐
│  1. 任务定义  │ ← 明确目标（调研？总结？对比？）
└──────┬───────┘
       ↓
┌──────────────┐
│  2. 资源收集  │ ← 打开相关网页（10-20 个标签）
└──────┬───────┘
       ↓
┌──────────────┐
│  3. 标签整理  │ ← 垂直标签栏 + 智能分组
└──────┬───────┘
       ↓
┌──────────────┐
│  4. AI 处理   │ ← Chat → @标签页 → 下指令
└──────┬───────┘
       ↓
┌──────────────┐
│  5. 模型对比  │ ← 切换 2-3 个模型对比结果
└──────┬───────┘
       ↓
┌──────────────┐
│  6. 结果导出  │ ← 复制/收藏/生成报告
└──────┬───────┘
       ↓
┌──────────────┐
│  7. 知识沉淀  │ ← 收藏 + AI 摘要 → 语义搜索
└──────────────┘
```

### 2.2 详细操作步骤

#### 场景 A：竞品调研报告（2 小时 → 20 分钟）

**传统方式：**
```
1. Google 搜索竞品关键词（15 分钟）
2. 逐个打开官网/评测/新闻（30 分钟）
3. 读文章 + 记笔记（45 分钟）
4. 整理对比表格（30 分钟）
5. 写分析报告（30 分钟）
总计：2.5 小时
```

**Tabbit 方式：**
```
Step 1: 收集资源（5 分钟）
├─ 打开 Tabbit
├─ 搜索"竞品 A 评测" → 打开前 5 个结果
├─ 搜索"竞品 B 评测" → 打开前 5 个结果
└─ 搜索"竞品 C 评测" → 打开前 5 个结果

Step 2: 整理标签（2 分钟）
├─ 左侧垂直标签栏查看
├─ 右键 → "智能分组" → 按竞品自动归类
└─ 保存为标签组"竞品调研_20260312"

Step 3: AI 处理（8 分钟）
├─ 点击右上角 Chat 图标
├─ 输入："@所有标签页，从以下维度整理对比表格：
│    - 核心功能
│    - 定价策略
│    - 目标用户
│    - 优劣势
│    每个结论附信息来源链接"
├─ 切换 Kimi 生成第一版
├─ 切换 DeepSeek 生成第二版
└─ 对比两个结果，取最优

Step 4: 深化分析（5 分钟）
├─ 追问："根据以上对比，给出我们的差异化建议"
├─ 追问："预测竞品下半年可能的动作"
└─ 收藏最终报告

总计：20 分钟
效率提升：7.5 倍
```

#### 场景 B：每日资讯速读（1 小时 → 10 分钟）

```
Step 1: 批量打开（3 分钟）
├─ 打开 36 氪/AI 科技评论/机器之心/量子位
└─ 每个网站打开今日 Top 5 文章

Step 2: 快速筛选（2 分钟）
├─ 垂直标签栏浏览标题
├─ 关闭低相关性文章
└─ 保留 8-10 篇核心文章

Step 3: AI 总结（5 分钟）
├─ Chat → @所有标签页
├─ 指令："总结今日 AI 行业重要动态，按以下分类：
│    - 大模型进展
│    - 融资并购
│    - 产品发布
│    - 政策监管
│    每条不超过 50 字"
└─ 复制到钉钉/飞书同步给团队

总计：10 分钟
```

#### 场景 C：学习新领域（3 天 → 2 小时）

```
Step 1: 建立知识框架（20 分钟）
├─ 搜索"XX 领域 入门指南"
├─ 搜索"XX 领域 知识图谱"
├─ 搜索"XX 领域 核心概念"
└─ 打开 10-15 篇基础文章

Step 2: AI 提取框架（15 分钟）
├─ Chat → @所有标签页
├─ 指令："提取 XX 领域的核心概念框架，包括：
│    - 关键术语定义
│    - 技术栈分层
│    - 主流工具/框架
│    - 学习路径建议"
└─ 收藏为"XX 领域_知识框架"

Step 3: 深度阅读（60 分钟）
├─ 根据框架，针对性打开深度文章
├─ 每篇用 Chat 总结核心观点
└─ 收藏 + 打标签

Step 4: 问答巩固（25 分钟）
├─ Chat → @收藏夹"XX 领域"
├─ 指令："出 10 道测试题，检验我对 XX 领域的理解"
├─ 答题 → 让 AI 批改
└─ 针对薄弱点补充阅读

总计：2 小时
```

## 3. 场景模板

### 3.1 妙招库（Prompt 模板）

#### 模板 1：文章总结专家
```
请总结这篇文章的核心观点，按以下结构：

【核心论点】（1 句话）
【关键论据】（3-5 点，每点 1 句话）
【数据支撑】（如有具体数字，列出）
【行动建议】（对读者的实际建议）
【我的评价】（客观评价文章质量）

要求：
- 保持原文核心意思，不曲解
- 标注不确定的信息
- 如有专业术语，括号内解释
```

#### 模板 2：多文档对比分析
```
@所有标签页

请从以下维度对比分析这些文档：

【维度 1：核心功能】
- 文档 A：...
- 文档 B：...
- 差异点：...

【维度 2：技术实现】
...

【维度 3：优缺点】
...

【综合建议】
...

要求：
- 每个结论必须标注来源（文档标题 + 段落）
- 如有矛盾信息，明确指出
- 用表格呈现核心对比
```

#### 模板 3：市场调研报告
```
任务：调研 [XX 市场/产品]

请执行以下步骤：
1. 搜索最新市场数据（2025-2026 年）
2. 识别 Top 5 竞品
3. 分析每个竞品的：
   - 核心功能
   - 定价策略
   - 用户评价
   - 融资情况
4. 总结市场趋势
5. 给出进入建议

输出格式：
- 执行摘要（200 字）
- 市场规模（数据 + 来源）
- 竞争格局（表格）
- 趋势分析（3-5 点）
- 风险与建议
```

#### 模板 4：代码/技术文档解读
```
请解读这份技术文档：

【核心功能】这个技术/库是做什么的？
【适用场景】什么时候应该用它？
【快速开始】最简单的使用示例
【关键 API】核心接口说明
【注意事项】常见坑和最佳实践
【替代方案】有没有其他选择？

要求：
- 代码示例用中文注释
- 复杂概念用类比解释
- 标注文档版本（如有）
```

#### 模板 5：决策辅助
```
背景：[描述你的决策场景]
选项：A / B / C
目标：[你想达成的目标]
约束：[预算/时间/资源限制]

请分析：
1. 每个选项的优缺点
2. 短期影响（1-3 个月）
3. 长期影响（6-12 个月）
4. 风险评估
5. 推荐选项 + 理由

要求：
- 客观中立，不偏向
- 标注不确定性
- 如有信息缺口，指出需要补充什么
```

## 5. 拓展场景

### 5.1 个人知识管理（PKM）

```
信息流：
网络文章 → Tabbit 收藏+AI 摘要 →
```

**优势：**
- Tabbit 负责"输入 + 初步处理"

## 6. 风险控制

### 6.1 依赖风险

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|---------|
| Tabbit 收费/限制 | 中 | 高 | 保持 OpenClaw 独立搜索能力 |
| 账号被封 | 低 | 高 | 不用自动化脚本滥用 |
| 服务关停 | 低 | 中 | 重要资料及时导出备份 |
| API 变更 | 中 | 低 | 不深度集成，保持松耦合 |

### 6.2 使用建议

**✅ 推荐做法：**
- 人工操作 + AI 辅助（不用自动化脚本）
- 重要资料及时导出备份
- 多模型对比，不盲信单一结果
- 定期清理标签组，保持整洁

**❌ 避免做法：**
- 用脚本高频调用（可能触发反滥用）
- 存储敏感信息（API Key/密码）
- 完全依赖 Tabbit（保持独立能力）
- 不验证 AI 输出（尤其是数据/引用）

### 6.3 退出策略

如果 Tabbit 不能用了：
1. 立即导出所有收藏/标签组
2. 恢复 OpenClaw + 原生搜索工作流
3. 考虑替代方案（Arc/Atlas/Perplexity）
