## 🎯 核心体验一句话

**"在随机生成的塔中攀爬，通过卡牌构筑和策略决策，打败三层 Boss 的 Roguelike 卡牌游戏。"**

---

## 🔄 核心循环

```
战斗 → 获得卡牌/遗物 → 休息点决策 → 下一场战斗 → Boss → 下一层
  ↑                                                        ↓
  └────────────── 死亡 / 通关 ← 第三层 Boss ←──────────────┘
```

**单局流程：**
1. **地图选择** — 在随机生成的节点间选择路径
2. **战斗** — 回合制卡牌战斗
3. **奖励** — 选择卡牌/遗物/药水
4. **休息点** — 休息 (回血) / 锻造 (删牌/升级)
5. **商店** — 用金币购买卡牌/遗物/药水
6. **Boss 战** — 每层结束与 Boss 战斗
7. **重复** — 进入下一层，直到通关或死亡

---

## 🎮 核心系统设计

### 1️⃣ 卡牌系统

**卡牌类型：**
- **攻击牌** — 造成伤害
- **技能牌** — 防御/增益/特殊效果
- **能力牌** — 整场战斗持续的被动效果
- **状态牌** — 负面牌 (受伤/诅咒)，占用卡手

**卡牌获取：**
- 战斗奖励 (3 选 1)
- 商店购买
- 事件奖励
- Boss 奖励

**卡牌升级：**
- 在休息点锻造
- 效果增强 (数值提升/费用降低/附加效果)

**设计亮点：**
- 每张卡牌都有明确用途
- 升级带来质变而非单纯数值
- 颜色区分 (攻击红/技能蓝/能力紫)

---

### 2️⃣ 遗物系统

**遗物类型：**
- **初始遗物** — 每个角色固定 1 个
- **普通遗物** — 白色边框，基础效果
- **罕见遗物** — 蓝色边框，较强效果
- **稀有遗物** — 金色边框，强力效果
- **Boss 遗物** — 红色边框，改变玩法
- **事件遗物** — 带负面效果

**设计亮点：**
- 遗物之间产生 Synergy (协同效应)
- Boss 遗物强制改变 Build 方向
- 负面遗物增加决策深度

---

### 3️⃣ 角色系统

**4 个角色 (截至 2026 年)：**

| 角色 | 特色 | 核心机制 |
|------|------|----------|
| **铁甲战士** | 力量/防御 | 力量成长、消耗牌 |
| **静默猎手** | 敏捷/毒 | 弃牌、中毒 |
| **故障机器人** | 充能球 | 电浆/冰霜/黑暗/闪电球 |
| **观者** | 姿态切换 | 愤怒/平静/神格姿态 |

**设计亮点：**
- 每个角色有完全不同的机制
- 同一角色不同 Build 差异巨大
- 角色难度递进 (战士→猎手→机器人→观者)

---

### 4️⃣ 地图系统

**三层结构：**
```
第一层 (1-12 节点) — 普通战斗为主
     ↓
Boss 1
     ↓
第二层 (1-12 节点) — 精英/事件增多
     ↓
Boss 2
     ↓
第三层 (1-8 节点) — 高难度战斗
     ↓
Boss 3 (最终 Boss)
```

**节点类型：**
- ⚔️ 战斗 — 普通敌人
- 🔥 精英 — 强敌 (必掉 Boss 遗物)
- ❓ 事件 — 随机事件
- 💰 商店 — 购物
- 🔥 休息点 — 休息/锻造
- 👑 Boss — 层底 Boss

**设计亮点：**
- 路径选择带来策略性
- 风险/回报权衡 (精英 vs 安全)
- 每层难度递进

---

### 5️⃣ 战斗系统

**回合制规则：**
- 每回合抽 5 张牌
- 每回合 3 点能量
- 牌打完后抽牌堆重洗
- 敌人意图可见 (下回合行动预告)

**战斗策略：**
- **防御优先** — 活着才有输出
- **能量管理** — 高效利用每点能量
- **牌序规划** — 考虑抽牌顺序
- **敌人意图** — 根据敌人行动调整

**设计亮点：**
- 意图系统降低随机性挫败感
- 能量限制防止单回合爆发过强
- 抽牌重洗机制让战斗有节奏感

---

## 📊 数值设计分析

### 伤害公式

```
实际伤害 = (卡牌基础伤害 + 力量) × 增益倍率 - 敌人格挡
```

**关键数值：**
- **力量** — 每点 +1 攻击伤害
- **敏捷** — 每点 +1 格挡
- **易伤** — 受到伤害 +50%
- **脆弱** — 造成伤害 -50%

### 经济系统

**金币获取：**
- 战斗奖励：20-60 金币
- 精英奖励：80-120 金币
- Boss 奖励：200-300 金币
- 事件：不定

**金币消耗：**
- 卡牌：50-300 金币
- 遗物：100-400 金币
- 药水：50-150 金币
- 休息点锻造：免费

## 🎯 Build 多样性

**常见 Build 类型：**

### 战士 Build
- **力量战** — 恶魔形态 + 力量增益
- **消耗战** — 消耗牌 + 无限循环
- **防御战** — 高格挡 + 反伤

### 猎手 Build
- **毒流** — 中毒叠加 + 伤害翻倍
- **弃牌流** — 弃牌触发 + 过牌
- **刀流** — 小刀叠加 + 多段攻击

### 机器人 Build
- **电球流** — 闪电球 + 聚焦
- **冰球流** — 冰霜球 + 防御
- **黑暗球流** — 黑暗球 + 高聚焦

### 观者 Build
- **愤怒流** — 愤怒姿态 + 高爆发
- **无限流** — 神格姿态 + 无限连招
- **平静流** — 平稳过渡 + 姿态切换

**Build 数量估算：**
- 每个角色 5-8 种主流 Build
- 总计 20-30 种可行 Build
- 每局随机性保证重复可玩性

## 💡 设计亮点总结

### 1. 完美的随机性控制
- 卡牌 3 选 1 降低随机挫败感
- 敌人意图可见降低不确定性
- 地图路径选择增加策略性

### 2. 深度 Synergy 系统
- 卡牌 × 遗物 × 角色 三重协同
- Build 之间差异巨大
- 每局都有新发现

### 3. 难度曲线平滑
- 三层递进设计
- 高塔 20 层难度阶梯
- 角色难度递进

### 4. 单局时长合理
- 30-60 分钟一局
- 随时可以暂停
- 适合碎片时间

### 5. 高重复可玩性
- 4 角色 × 多种 Build
- 每日挑战
- 高塔模式

## 📝 可借鉴的设计

### 适用于手游的设计

1. **3 选 1 奖励** — 降低随机性，增加掌控感
2. **意图预告** — 降低挫败感，增加策略性
3. **短单局** — 适合移动端碎片时间
4. **Build 多样性** — 长期留存保障
5. **每日挑战** — 日活保障

### 需要调整的设计

1. **付费点** — 原买断制，手游需设计内购
2. **难度** — 原硬核，手游需降低门槛
3. **美术风格** — 原欧美风，国内需本地化

## 🎯 对我们的启发

### 系统策划角度

1. **核心循环清晰** — 战斗→奖励→决策→战斗
2. **数值可验证** — 伤害公式简单透明
3. **Build 有辨识度** — 每种玩法有明确特征
4. **难度可控** — 通过数值和敌人配置调节

### 数值策划角度

1. **成长感知强** — 力量/敏捷每点都有用
2. **倍率设计合理** — 易伤/脆弱 50% 好计算
3. **经济闭环** — 金币获取/消耗平衡

### 关卡策划角度

1. **节点密度合理** — 每层 10-12 个节点
2. **风险/回报平衡** — 精英 vs 普通战斗
3. **Boss 战节奏** — 每层结束有成就感
