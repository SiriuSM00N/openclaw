## 1. 核心循环架构

### 1.1 基础循环（1:1 传承）

```
┌─────────────────────────────────────────────────────────────┐
│                    单局核心循环                              │
│                                                              │
│   开始 → 选择路径 → 战斗节点 → 奖励选择 → 休息节点         │
│              ↓                              ↑                │
│         精英节点 ←────────────────────── 事件节点           │
│              ↓                                               │
│           BOSS → 下一层（重复 3 次）→ 最终 BOSS → 结局       │
└─────────────────────────────────────────────────────────────┘
```

**节点类型与功能：**

| 节点类型 | 功能 | 设计意图 |
|---------|------|---------|
| **未知 (?)** | 随机事件（战斗/精英/商店/休息） | 增加不确定性 |
| **战斗** | 普通敌人，掉落卡牌 | 基础资源获取 |
| **精英** | 强敌，掉落遗物 | 高风险高回报 |
| **休息** | 治疗/升级卡牌 | 资源管理决策点 |
| **商店** | 购买卡牌/遗物/药水 | 经济系统出口 |
| **宝箱** | 免费遗物 | 正向反馈 |
| **事件** | 叙事 + 选择 | 世界观渗透 |

### 1.2 资源循环

```
┌──────────────────────────────────────────────────────┐
│                  资源流动图                           │
│                                                       │
│   生命 ──→ 战斗消耗 ──→ 休息恢复 ──→ 归零失败      │
│     ↓                                                  │
│   能量 ──→ 卡牌消耗 ──→ 回合重置                      │
│     ↓                                                  │
│   金币 ──→ 商店购买 ──→ 卡牌/遗物/药水               │
│     ↓                                                  │
│   卡牌 ──→ 牌组构建 ──→ 战斗效能 ──→ 生存率         │
│     ↓                                                  │
│   遗物 ──→ 被动增益 ──→ build 成型                   │
└──────────────────────────────────────────────────────┘
```

**关键设计原则：**

1. **资源稀缺性** — 生命不可再生（除休息点），创造紧张感
2. **能量硬限制** — 每回合 3 能量，限制单回合爆发上限
3. **牌组膨胀风险** — 卡牌越多越难抽到核心卡，抑制无脑拿卡

## 2. 多人合作系统设计

### 2.1 架构设计

| 设计维度 | 实现方式 | 设计意图 |
|---------|---------|---------|
| **地图导航** | 共享地图，共同决策 | 创造协商空间 |
| **牌组管理** | 各自独立 | 保持个人责任 |
| **生命池** | 各自独立 | 避免一人拖后腿 |
| **遗物获取** | 各自拾取，可商议 | 增加社交互动 |
| **BOSS 血量** | 按人数倍增 | 平衡难度曲线 |

### 2.2 状态叠加机制

```
玩家 A 施加「易伤」 → 敌人受到伤害 ×1.5
                          ↓
玩家 B 攻击 → 享受易伤加成

设计意图：创造职业分工，避免同质化 build
```

**协同效果表：**

| 玩家 A 角色 | 玩家 B 角色 | 协同效果 | 评分 |
|-----------|-----------|---------|------|
| 铁甲战士 | 沉默猎人 | 易伤 + 中毒 | ⭐⭐⭐⭐⭐ |
| 故障机器人 | 亡灵契约师 | 能量生成 + 召唤吸收 | ⭐⭐⭐⭐ |
| 沉默猎人 | 亡灵契约师 | 弃牌 + 墓地回收 | ⭐⭐⭐⭐⭐ |
| 铁甲战士 | 亡灵契约师 | 牺牲 + 续航 | ⭐⭐⭐ |

### 2.3 多人专属卡牌

**设计特点：**
- 仅在合作模式出现
- 效果围绕团队机制（传递资源、掩护防御、连击链）
- 创造与单人完全不同的体验

**示例卡牌：**
```
「引火」（故障机器人专属）
效果：将 1 个充能球转移给队友
设计意图：资源分享，创造跨玩家 combo
```

### 2.4 多人设计风险与解决方案

| 风险 | 表现 | 解决方案 |
|-----|------|---------|
| **战斗时长过长** | 4 人局 90 分钟+ | 优化敌人血量 scaling |

```
│   Layer 1: 基础属性（生命/能量/起始卡） │
│        ↓                                  │
│   Layer 2: 核心机制（充能球/中毒/易伤）  │
│        ↓                                  │
│   Layer 3: 专属资源（辉星/灵魂/星辰）    │

│   Layer 4: 终极 build（无限/秒杀/龟壳）  │
└─────────────────────────────────────────┘
```

### 3.2 储君（The Regent）机制拆解

#### 双能量系统

```
普通能量（每回合恢复）    辉星能量（不自动恢复）
        ↓                        ↓
   基础卡牌消耗            高阶卡牌消耗
        ↓                        ↓
   维持日常运转            爆发/终结技
```

**设计意图：**
- 增加资源管理维度
- 创造"启动期→爆发期"的节奏变化
- 高风险（辉星难恢复）高回报（强力卡牌）

#### 锻造系统

```
铸造牌 → 生成「君王之剑」（2 费特殊卡）
           ↓
      铸造层数提升
           ↓
      君王之剑攻击力无限成长
```

**数值设计：**
- 启动慢（需要多回合铺垫）
- 成长无上限（满足数值膨胀快感）
- 脆弱（怕消耗/封印）

#### 核心卡牌分析

| 卡牌名 | 费用 | 效果 | 设计定位 |
|-------|------|-----|---------|
| 群星之子 | 能力 | 每回合生成辉星 | 核心引擎 |
| 伽马爆破 | 3 蓝 | 直伤，可起手 | 应急输出 |
| 辉光 | 1 | 生成 2 星 + 摸 2 | 运转核心 |
| 星界脉冲 | 0 | 14 点 AOE | 前期过渡 |
| 大爆炸 | 能力 | 给星给费 + 敲固有 | 启动加速器 |

### 3.3 亡灵契约师机制拆解

#### 墓地系统

```
传统设计：消耗堆 = 卡牌坟墓（永久消失）
    ↓
契约师设计：消耗堆 = 第二手牌（可回收）
    ↓
设计意图：负面机制正向化，创造新 build 可能
```

#### 召唤系统

```
「奥斯提」（骨头巨手）
├─ 独立血量条
├─ 自动吸收超额伤害
├─ 死亡后下回合 1HP 复活
└─ 可通过「召唤」卡牌提升血量上限

设计意图：第二生命池，提高容错率
```

#### 鲜血魔法

```
消耗 HP → 换取以下效果
    ├── 额外抽牌
    ├── 巨额伤害
    └── 单回合强力效果

风险等级：★★★★★
回报等级：★★★★★
```

#### 灾厄效果

```
机制：敌人身上的层数效果
触发：敌人血量 < 层数时 → 即死
时机：敌人行动后结算

设计意图：斩杀机制，创造反杀可能
风险：需要存活到结算时
```

### 4.2 附魔系统（Enchantments）

#### 设计架构

```
基础卡牌 + 附魔 = 强化卡牌

示例：
攻击卡（6 伤害）+ 易伤附魔 = 攻击后施加 1 层易伤
技能卡（格挡 5）+ 荆棘附魔 = 格挡后反弹 3 伤害
```

#### 设计意图

| 传统升级 | 附魔系统 |
|---------|---------|
| 数值提升（6→9） | 机制增强（新增效果） |
| 线性成长 | 组合式成长 |
| 重复卡牌枯燥 | 同样卡牌不同体验 |

#### 策划借鉴

```
适用场景：
- 卡牌/装备/技能系统需要深度定制
- 希望增加 build 多样性
- 减少数值膨胀压力

实现要点：
- 附魔池需要精心设计（避免破坏平衡）
- 附魔获取方式影响节奏（商店/掉落/合成）
- 附魔可叠加性决定上限（无限/有限）
```

## 5. 数值设计框架（⭐ 重点章节）

### 5.1 战斗数值模型

#### 核心公式

```
实际伤害 = 卡牌伤害 × (1 + 易伤系数) × (1 + 力量加成) - 敌方格挡

其中：
- 易伤系数 = 易伤层数 × 0.5（50% 增伤/层）
- 力量加成 = 力量值 × 0.1（每点力量 +10% 伤害）
- 虚弱系数 = 虚弱层数 × 0.5（50% 减伤/层）
```

#### 伤害类型与计算优先级

```
计算顺序：
1. 基础伤害（卡牌数值）
2. 力量/脆弱修正（加法）
3. 易伤/虚弱修正（乘法）
4. 格挡减免（减法）
5. 最终伤害（最低为 0）

伤害类型：
├─ 普通伤害 — 基础计算
├─ AOE 伤害 — 多目标，每目标独立计算
├─ 持续伤害 — 回合结束结算（中毒/燃烧）
│   └─ 中毒伤害 = 层数 × 3（不受力量影响）
└─ 斩杀伤害 — 条件触发（灾厄/即死效果）
```

#### 数值设计原则

| 原则 | 说明 | 示例 |
|-----|------|-----|
| **线性成长** | 基础伤害随费用线性增长 | 1 费 8 伤 → 2 费 14 伤 → 3 费 20 伤 |
| **乘法放大** | 易伤/虚弱用乘法，放大差异 | 易伤 2 层 = 2.25 倍伤害 |
| **递减收益** | 格挡超额部分不累积 | 格挡 10 受击 5 = 剩余 5（不累积） |
| **风险回报** | 鲜血魔法等 HP 交换高收益 | 消耗 3HP = 抽 2 卡 +3 能量 |

### 5.2 敌人血量 Scaling（详细数值）

#### 基础血量表（1 代参考 → 2 代调整）

| 敌人类型 | 1 代 Act1 | 1 代 Act2 | 1 代 Act3 | 2 代 Act1 | 2 代 Act2 | 2 代 Act3 |
|---------|----------|----------|----------|----------|----------|----------|
| **普通敌人** | 40-50 | 55-70 | 75-90 | 45-55 | 60-75 | 80-95 |
| **精英敌人** | 110-130 | 150-180 | 200-240 | 120-140 | 160-190 | 210-250 |
| **BOSS** | 400-480 | 500-600 | 600-720 | 420-500 | 520-620 | 630-750 |

**2 代调整趋势：**
- 整体血量 +10%~15%（延长战斗，展示新机制）
- 精英/Boss 血量提升更多（检验 build 强度）

#### 多人血量 Scaling 公式

```
基础血量 = 单人血量 × 人数系数

人数系数设计：
| 人数 | 系数 | 人均血量 | 设计意图 |
|------|------|---------|---------|
| 1 人 | ×1.0 | 100% | 基准 |
| 2 人 | ×1.8 | 90%/人 | 鼓励 2 人配合 |
| 3 人 | ×2.5 | 83%/人 | 协同收益 |
| 4 人 | ×3.2 | 80%/人 | 规模不经济 |

设计意图：
- 非线性增长（人数越多，人均血量越低）
- 鼓励配合而非简单堆人数
- 4 人局需要更好的协同才能高效
```

#### 层数难度系数

```
每层血量 multiplier = 1.2^n

Act 1（层 1-12）：
- 第 1 场战斗：100%
- 第 6 场战斗：100% × 1.2^5 = 249%
- Boss（第 12 场）：100% × 1.2^11 = 743%

设计意图：
- 可预测的难度曲线
- 玩家需要规划升级节奏
- 后期战斗检验 build 成型度
```

### 5.3 卡牌数值设计（详细表）

#### 攻击卡数值表

| 费用 | 基础伤害 | 升级后 | 代表卡牌 | 设计定位 |
|-----|---------|-------|---------|---------|
| **0 费** | 4-6 | +2 | 痛击、防御 | 填充/应急 |
| **1 费** | 7-10 | +3 | 重击、连续拳 | 核心运转 |
| **2 费** | 12-16 | +4 | 重劈、双重横砍 | 主力输出 |
| **3 费** | 18-24 | +6 | 处决、毁灭 | 爆发/终结 |
| **X 费** | 6×X | +2×X | 处决、无限刀 | 特殊机制 |

**数值设计逻辑：**
```
费用效率曲线：
0 费：4-6 伤（效率 4-6 伤/费）
1 费：7-10 伤（效率 7-10 伤/费）← 峰值
2 费：12-16 伤（效率 6-8 伤/费）
3 费：18-24 伤（效率 6-8 伤/费）

设计意图：
- 1 费卡牌效率最高（鼓励运转）
- 高费卡牌总伤高但效率略低（平衡启动成本）
- 0 费卡牌效率最低（平衡无成本优势）
```

#### 技能卡数值表（防御向）

| 费用 | 基础格挡 | 升级后 | 附加效果 | 代表卡牌 |
|-----|---------|-------|---------|---------|
| **0 费** | 3-5 | +2 | 无 | 快速躲闪 |
| **1 费** | 6-9 | +3 | 抽 1/易伤 1 | 铁波、痛击 |
| **2 费** | 10-14 | +4 | 抽 2/格挡×2 | 巩固、全身而退 |
| **3 费** | 15-20 | +6 | 大量过牌/无敌 | 壁垒 |

#### 能力卡数值设计

```
能力卡设计原则：
- 不消耗（整局生效）
- 费用偏高（2-3 费）
- 收益需要多回合摊薄

示例：
「力量」能力卡
- 费用：2
- 效果：每回合开始 +1 力量
- 回本计算：
  - 第 1 回合：-2 费 +0 收益（亏）
  - 第 2 回合：+1 伤（回本 10%）
  - 第 5 回合：+5 伤（回本 50%）
  - 第 10 回合：+10 伤（回本 100%+）

设计意图：
- 长局收益高，短局收益低
- 创造"投资 vs 即时"决策
- 鼓励玩家规划战斗节奏
```

### 5.4 经济系统（详细数值）

#### 金币获取表

| 来源 | 数值范围 | 期望值 | 备注 |
|-----|---------|-------|-----|
| **普通战斗** | 10-30 金 | 18 金 | 基础来源 |
| **精英战斗** | 50-80 金 | 65 金 | 高风险高回报 |
| **BOSS 战斗** | 100-150 金 | 120 金 | 通关奖励 |
| **事件（金币）** | 20-100 金 | 50 金 | 随机 |
| **售卖卡牌** | 卡牌价值 40-60% | 50% | 回收机制 |

**单局期望收入（完整通关）：**
```
普通战斗 × 15 场 = 15 × 18 = 270 金
精英战斗 × 3 场 = 3 × 65 = 195 金
BOSS 战斗 × 3 场 = 3 × 120 = 360 金
事件（平均） = 100 金
─────────────────────────────
总计期望 ≈ 925 金/局
```

#### 金币消耗表

| 消费项 | 价格范围 | 建议占比 | 设计意图 |
|-------|---------|---------|---------|
| **购买卡牌** | 40-100 金 | 40% | 牌组核心来源 |
| **购买遗物** | 150-300 金 | 35% | build 成型关键 |
| **购买药水** | 50-80 金 | 15% | 应急资源 |
| **事件消耗** | 随机 | 10% | 随机体验 |

**经济平衡检查：**
```
收入 925 金 - 支出 925 金 = 0（设计平衡点）

实际玩家行为：
- 新手：花费不足（不敢花）→ 通关率低
- 老手：高效花费（精准购买）→ 通关率高
- 设计意图：经济决策也是技术体现
```

### 5.5 角色数值对比（2 代）

| 角色 | 生命 | 能量 | 起始格挡 | 起始攻击 | 设计定位 |
|-----|------|------|---------|---------|---------|
| **铁甲战士** | 72 | 3 | 5 | 6 | 坦克/易伤 |
| **沉默猎人** | 65 | 3 | 5 | 5 | 敏捷/中毒 |
| **故障机器人** | 68 | 3 | 5 | 5 | 成长/充能球 |
| **储君** | 70 | 3+ 辉星 | 5 | 6 | 爆发/锻造 |
| **亡灵契约师** | 63+ 奥斯提 | 3 | 4 | 5 | 召唤/鲜血 |

**设计分析：**
- 铁甲生命最高（坦克定位）
- 猎人生命最低（高风险高输出）
- 契约师生命最低但有奥斯提补偿（第二生命池）
- 储君双能量系统（独特资源管理）

### 5.6 数值平衡检查清单

```
□ 单卡强度检查
  - 0 费卡是否过强？（避免无成本 combo）
  - 3 费卡是否过弱？（确保高费有价值）
  
□ 组合强度检查
  - 是否存在无限 combo？（如弃牌 + 回收）
  - 是否存在必杀 combo？（如易伤 + 爆发）
  
□ 难度曲线检查
  - Act1 通关率是否 40-60%？
  - Act2 通关率是否 20-30%？
  - Act3 通关率是否 10-15%？
  
□ 经济平衡检查
  - 玩家是否有钱花不完？（通货膨胀）
  - 玩家是否永远不够钱？（卡资源）
  
□ 多人平衡检查
  - 2 人局是否比单人简单 20-30%？
  - 4 人局是否比单人简单 40-50%？
  - 是否存在人数越多越难的情况？（需要调整 scaling）
```

## 6. 成长与进度系统

### 6.1 单局成长（Roguelike）

```
牌组构建 → 战斗验证 → 调整优化 → BOSS 检验
    ↓
遗物收集 → 被动增益 → build 成型
    ↓
药水管理 → 应急资源 → 关键时刻使用
```

### 6.2 跨局成长（Meta Progression）

| 解锁类型 | 解锁条件 | 奖励内容 |
|---------|---------|---------|
| **卡牌解锁** | 角色使用次数 | 新卡牌加入卡池 |
| **遗物解锁** | 完成特定成就 | 新遗物加入卡池 |
| **角色解锁** | 通关前作角色 | 新角色可用 |
| **历史节点** | 推进攻略进度 | 碎片化剧情 + 奖励 |

### 6.3 进阶系统（Ascension）

```
进阶 0 → 进阶 1 → ... → 进阶 20

每层增加难度：
├─ 敌人血量提升
├─ 敌人伤害提升
├─ 初始生命降低
├─ 事件负面选项增加
└─ 特殊规则激活（如卡牌升级成本增加）

设计意图：
- 提供长期挑战目标
- 难度曲线可控
- 高端玩家展示空间
```

## 7. 可借鉴的设计模式

### 7.1 多人合作设计模式

```
适用场景：合作 PVE 游戏

核心原则：
1. 共享目标 + 独立责任
2. 状态叠加创造协同
3. 专属内容区分体验
4. 难度 scaling 非线性

实现检查清单：
□ 是否有职业分工空间？
□ 是否有资源分享机制？
□ 是否有跨玩家 combo？
□ 难度 scaling 是否合理？
□ 是否有防搭便车机制？
```

### 7.2 双资源系统设计模式

```
适用场景：需要增加决策深度的系统

设计模板：
资源 A（可恢复）→ 维持日常运转
资源 B（难恢复）→ 爆发/终结技

风险：
- 资源 B 获取过难 → 玩家永远不用
- 资源 B 获取过易 → 失去设计意义
- 两套资源无联动 → 割裂感

解决方案：
- 设计资源转换途径
- 核心卡牌同时消耗两种资源
- 平衡获取节奏
```

### 7.3 负面机制正向化模式

```
适用场景：希望创造独特 build

设计模板：
传统认知：X 机制 = 负面（如消耗、弃牌）
    ↓
重新设计：X 机制 = 资源（可回收、可转化）
    ↓
代表案例：
- 亡灵契约师：消耗堆 = 墓地 = 第二手牌
- 沉默猎人：弃牌 = 奇巧触发 = 额外效果

设计要点：
□ 需要明确告知玩家机制
□ 回收/转化途径要稳定
□ 强度需要平衡（避免无限 combo）
```

### 7.4 附魔/词缀系统设计模式

```
适用场景：装备/技能/卡牌定制

设计模板：
基础物品 + 随机词缀 = 个性化物品

词缀池设计：
├─ 前缀（攻击向）：易伤、吸血、穿透...
├─ 后缀（防御向）：格挡、反伤、回复...
└─ 特殊（机制向）：触发、转换、复制...

平衡要点：
□ 词缀强度分级（普通/稀有/传奇）
□ 词缀互斥规则（避免破坏平衡组合）
□ 获取方式控制节奏
```

### 7.5 Roguelike 循环设计模式

```
适用场景：肉鸽类游戏

核心循环：
探索 → 战斗 → 奖励 → 成长 → 更强战斗 → BOSS

关键设计点：
1. 节点类型多样性（避免单调）
2. 奖励选择有意义（不是无脑拿）
3. 难度曲线可预测（玩家能规划）
4. 失败惩罚适中（愿意再来一局）
5. 单局时长控制（30-60 分钟）
```
