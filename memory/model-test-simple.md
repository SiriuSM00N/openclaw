## 📝 测试题目（4 道核心题）

### 题 1：游戏系统设计（核心场景）
```
请设计一个 Roguelike 手游的成长系统，包括：
1. 局外成长（永久升级）
2. 局内成长（单局强化）
3. 两种成长的循环关系

要求：结构清晰，可直接用于策划文档
```

**评估：** 系统完整性、逻辑自洽、可落地性

---

### 题 2：代码能力
```
用 Python 写一个函数，模拟角色成长曲线：
- 输入：角色等级（1-100）
- 输出：所需经验值
- 曲线类型：指数增长，后期放缓
- 要求：可调整参数，有注释

额外：生成等级 - 经验曲线图
```

**评估：** 代码正确性、质量、可运行性

---

### 题 3：长文本理解
```
（需要一份 3000+ 字的文档）

任务：
1. 总结核心观点（200 字内）
2. 提取关键信息点（bullet list）
3. 指出可能的逻辑漏洞
```

**评估：** 理解准确度、总结精炼度

---

### 题 4：日常对话
```
请用通俗易懂的方式解释：
1. 什么是"核心游戏循环"？
2. 什么是"付费点设计"？

要求：给外行讲也能听懂，有例子
```

**评估：** 表达清晰度、对话自然度
