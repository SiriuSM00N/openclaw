## 📋 功能确认（来自实测）

### 1. 模型切换
**位置：** 右上角 Chat 图标 → 模型下拉菜单
**默认：** 自动选择"最佳"
**操作：** 手动切换 14 个模型

### 2. AI Chat 入口
**位置：** 右上方图标
**功能：**
- 侧边栏对话
- 斜杠命令（/润色、/解释、/总结、/脚本盲盒）
- @标签页引用
- 上传本地文件
- 截图对话

### 3. 妙招功能
**入口：** 右上角头像 → "我的妙招" 或 💡按钮
**创建方式：**
- 提示词
- JS 脚本
- 智能代理（支持变量）

### 4. 标签管理
- 纵向/横向布局切换
- 智能分组
- 一键展开/折叠
- 工作区保存

### 5. Chrome 插件兼容
✅ 支持 Chrome 扩展
✅ 开发者模式
✅ 迁移成本低

## 🚀 落地执行流程（更新版）

### Day 1：环境搭建（30 分钟）

```
1. 确认版本：国际版 ✅
2. 设置默认浏览器 → 解锁 Pro 功能 ✅
3. 打开 Tabbit，右上角点 Chat 图标
4. 模型下拉菜单截图 → 确认 14 个模型都能用
5. 每个模型问"1+1=?"测试响应
```

### Day 2：模型评测（1 小时）

```
准备 10 道测试题：
- 逻辑推理（2 题）
- 代码生成（2 题）
- 创意写作（2 题）
- 翻译（2 题）
- 长文本总结（2 题）

用 14 个模型分别作答
→ 记录每个模型的表现
→ 输出评测表格
→ 建立"场景 - 模型"映射
```

### Day 3：工作流建设（2 小时）

```
1. 创建 5 个妙招：
   - 文章总结专家
   - 多文档对比
   - 报告生成
   - 代码审查
   - 翻译优化

2. 建立标签组模板：
   - 竞品监控_每周
   - 行业情报_每日
   - 学习_XX 领域
   - 项目_XXX

3. 测试一次完整调研任务
```

### Day 4-7：集成优化

```
1. Tabbit + OpenClaw 工作流对接
2. 导出功能测试
3. 每日调用量统计
4. 优化模型选择策略
```

## ⚠️ 风险与注意事项

### 1. 调用限制（待确认）
- 公测期可能无限调用
- 但可能有速率限制（RPM）
- 建议：不要脚本高频调用

### 2. 政策风险
- 国外模型在中国使用可能有合规问题
- 建议：重要内容及时导出

### 3. 稳定性
- 公测期可能随时调整政策
- 建议：趁现在多用，建立工作流

### 4. 数据隐私
- 使用国外模型数据可能出境
- 建议：不存储敏感信息
