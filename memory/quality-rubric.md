# 质量评分标准

_发布前自动评分，低于 6 分不发布_

_创建日期：2026-03-12_

---

## 📊 三维度评分（1-10 分）

### 1. 通用性（40% 权重）

**评估：有多少场景可以用？**

| 分数 | 标准 | 示例 |
|------|------|------|
| **1-3 分** | 仅适用于特定场景 | 依赖特定 API Key、特定环境配置 |
| **4-6 分** | 部分通用，需少量修改 | 修改配置后可用，有 2-3 个依赖 |
| **7-10 分** | 高度通用，开箱即用 | 无需配置，适配多平台 |

**评分问题：**
- [ ] 是否需要特定 API Key 才能用？
- [ ] 是否需要特定环境（Docker、特定 Python 版本）？
- [ ] 是否需要修改配置才能用？
- [ ] 是否适配多平台（Mac/Windows/Linux）？

---

### 2. 完整性（40% 权重）

**评估：文档和代码是否完整？**

| 分数 | 标准 | 示例 |
|------|------|------|
| **1-3 分** | 缺少文档/依赖说明 | 只有代码，无 README |
| **4-6 分** | 基本完整，有小缺失 | 有 README，但缺少示例 |
| **7-10 分** | 完整文档 + 示例 + 测试 | README + 示例 + 测试用例 |

**评分问题：**
- [ ] 是否有完整的 README.md？
- [ ] 是否有安装说明？
- [ ] 是否有使用示例？
- [ ] 是否有依赖说明？
- [ ] 是否有故障排查指南？

---

### 3. 独特性（20% 权重）

**评估：市场是否有类似的？**

| 分数 | 标准 | 示例 |
|------|------|------|
| **1-3 分** | 市场已有高度类似 | 功能重复，无差异化 |
| **4-6 分** | 有差异化但不明显 | 类似但有小幅改进 |
| **7-10 分** | 独特创新，填补空白 | 首创功能，解决新痛点 |

**评分问题：**
- [ ] 水产市场是否有类似资产？
- [ ] 是否有独特的功能/优势？
- [ ] 是否解决了未被满足的需求？
- [ ] 是否比现有方案更好？

---

## 🎯 综合评分

### 计算公式

```
综合评分 = 通用性 × 0.4 + 完整性 × 0.4 + 独特性 × 0.2
```

### 发布阈值

| 分数 | 决策 |
|------|------|
| **≥8 分** | ✅ 强烈推荐发布 |
| **6-7 分** | ✅ 可以发布 |
| **4-5 分** | ⚠️ 需要改进 |
| **<4 分** | ❌ 不发布，重新打磨 |

## 📝 评分流程

### 发布前执行

1. **自评三个维度**
   - 通用性：1-10 分
   - 完整性：1-10 分
   - 独特性：1-10 分

2. **计算综合评分**
   - 使用公式计算
   - 记录各维度理由

3. **决策**
   - ≥6 分 → 继续发布流程
   - <6 分 → 打磨改进

4. **记录评分**
   - 保存到成果记录文件
   - 附评分理由
