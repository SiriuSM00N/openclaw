## 🎯 5 道题目（统一主题：黄金矿工）

### 题 1：系统设计
**题目：** 设计一个黄金矿工小游戏的增益卡牌系统

**要求：**
1. 10-15 张增益卡牌
2. 每张卡牌包括：名称、效果、稀有度、获取方式
3. 简单数值规划（效果强度、持续时间）
4. 分析哪些卡牌组合会比较有趣

**输出：** JSON 格式

**考察维度：** 系统设计能力

---

### 题 2：代码生成
**题目：** 用 TypeScript 写一个黄金矿工钩子的状态机

**要求：**
1. 至少包含 5 个状态（如：待命、摆动、发射、回收、抓取中）
2. 每个状态有明确的进入/退出逻辑
3. 处理边界情况（如：钩到石头 vs 钩到金块）
4. 代码可直接运行

**输出：** TypeScript 代码

**考察维度：** 代码生成能力

---

### 题 3：代码审查
**题目：** 审查以下黄金矿工钩子代码，找出问题并给出修复建议

```typescript
class Hook { 
  x: number = 0; 
  y: number = 0; 
  state: string = 'idle';
  
  update() {
    if (this.state === 'swinging') { 
      this.x += Math.sin(Date.now() / 1000) * 5; 
    } 
    if (this.state === 'reeling') { 
      this.y -= 10; 
    } 
  }
  
  catch(item: Item) {
    this.state = 'reeling'; 
    // TODO: add item 
  } 
}
```

**要求：**
1. 找出至少 3 个 Bug 或设计问题
2. 给出修复代码
3. 说明每个问题的影响

**输出：** 问题列表 + 修复代码

**考察维度：** 代码审查能力

---

### 题 4：创意评估
**题目：** 有人设计了以下黄金矿工卡牌："时间暂停"：暂停游戏时间 10 秒，玩家可以继续操作

**请评估：**
1. 这张卡牌有趣吗？为什么？（1-10 分）
2. 会破坏游戏平衡吗？为什么？
3. 如果要改进，你会怎么改？
4. 提出 3 张更有创意的卡牌设计

**输出：** 评估报告 + 新卡牌设计

**考察维度：** 创意评估能力

---

### 题 5：概念解释
**题目：** 向完全没玩过游戏的人解释以下概念：
1. 连击（Combo）
2. 稀有度（Rarity）
3. DPS（每秒伤害）
4. 资源循环（Resource Loop）

**要求：**
1. 每个概念用黄金矿工举例说明
2. 让外行能听懂
3. 每个概念解释不超过 100 字

**输出：** 概念解释列表

**考察维度：** 表达清晰能力
