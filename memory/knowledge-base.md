### 代码基础（针对策划）

**学习目标：**
- 能读懂程序写的代码
- 能写简单脚本验证设计
- 能和程序高效沟通
- 能自己做简单原型

**推荐语言：**
1. **Lua** — 游戏脚本常用，易学
2. **Python** — 数据处理、自动化
3. **C#** — Unity 脚本，如果想深入

**学习资源：**
- Codecademy
- Unity Learn
- B 站教程

## 📅 学习计划

### 第 1 个月：关卡设计基础

**周 1-2：** 基础理论
- [ ] 阅读关卡设计基础资料
- [ ] 学习核心概念（引导、节奏、难度曲线）
- [ ] 小虾米整理笔记

**周 3-4：** 案例分析
- [ ] 拆解 3 个游戏的关卡设计
- [ ] 绘制关卡地图
- [ ] 分析设计意图

**产出：** 关卡设计笔记 + 3 份拆解文档

---

### 第 2 个月：Roguelike 设计深度

**周 1-2：** 核心循环
- [ ] 学习 Roguelike 核心设计原则
- [ ] 拆解 5 款 Roguelike 的核心循环
- [ ] 对比分析

**周 3-4：** Build 多样性
- [ ] 学习 Build 设计方法
- [ ] 分析各游戏的 Build 数量和质量
- [ ] 练习设计自己的 Build 体系

**产出：** Roguelike 设计笔记 + 5 份拆解文档

---

### 第 3-6 个月：代码基础

**月 3：** Lua/Python 基础
- [ ] 学习语法基础
- [ ] 完成小练习
- [ ] 写简单脚本

**月 4-5：** Unity 基础
- [ ] 学习 Unity 界面和工作流
- [ ] 理解 GameObject、Component
- [ ] 能修改简单脚本

**月 6：** 小项目实践
- [ ] 用 Unity 做一个简单原型
- [ ] 实现一个完整的游戏循环
- [ ] 小虾米辅助写代码

**产出：** 代码学习笔记 + 1 个可玩原型
