## 🔄 替补方案（完整版）

### 设计原则

```
1. OpenClaw 核心能力独立（不依赖 Tabbit）
2. 每个场景有 2+ 备选方案
3. 切换成本低（SOP 文档化）
4. 定期验证替补方案可用性
```

---

### 场景 1：每日资讯速读

**主方案 (T0)：** Tabbit + Gemini-Pro
- 流程：打开 10 网站 → @所有 → Gemini-Pro 总结 → 导出
- 时间：10 分钟
- 成本：免费

**替补 T1：** OpenClaw + Tavily + qwen3.5-plus
- 流程：web_search 搜关键词 → 读取 Top 10 URL → qwen3.5-plus 总结
- 时间：15 分钟
- 成本：Tavily 已付费

**替补 T2：** OpenClaw + Exa + qwen3.5-plus
- 流程：exa-search 搜关键词 → 读取结果 → qwen3.5-plus 总结
- 时间：15 分钟
- 成本：Exa 已付费

**替补 T3：** 手动 + AI
- 流程：人工打开网站 → 复制内容 → OpenClaw 总结
- 时间：30 分钟
- 成本：免费

**切换 SOP：**
```
1. 检测 Tabbit 不可用（连续失败 3 次）
2. 启用 T1 方案（修改 Cron 任务 payload）
3. 通知用户已切换
```
