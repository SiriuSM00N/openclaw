## 1. 游戏概览
- **游戏类型：**
- **开发商/发行商：**
- **发售日期：**
- **平台：**
- **核心玩法循环：**（一句话描述）

## 2. 核心循环分析

### 2.1 单局流程
```
[开始] → [探索/战斗] → [成长] → [挑战 Boss] → [死亡/通关] → [局外成长] → [新一轮]
```

### 2.2 局外成长
- 永久解锁内容
- 元进度系统
- 解锁驱动力

### 2.3 循环驱动力
- 玩家为什么再来一局？
- 随机性来源
- 成长感来源

## 3. 系统设计

### 3.1 战斗系统
- 核心战斗机制
- 攻击/防御/技能设计
- 敌人类型与设计
- Boss 设计原则

### 3.2 成长系统
- **局内成长：**
  - 道具/遗物/卡牌系统
  - 技能/能力获取
  - 数值成长曲线
- **局外成长：**
  - 永久解锁内容
  - 解锁条件
  - 成长节奏

### 3.3 经济系统
- **货币类型：**（名称 + 用途）
- **产出途径：**
- **消耗途径：**
- **经济循环：**（图示或文字描述）

### 3.4 关卡系统
- 关卡结构（线性/分支/随机）
- 房间/关卡类型
- 难度递进设计
- 奖励分布

### 3.5 叙事系统（如有）
- 叙事方式（碎片化/线性/环境叙事）
- 剧情结构
- 角色塑造方法

## 4. 数值分析

### 4.1 关键数值公式
- 伤害计算公式
- 成长曲线公式
- 概率设计

### 4.2 数值平衡
- 职业/角色平衡
- 道具强度平衡
- 难度曲线

### 4.3 经济数值
- 产出/消耗比
- 通胀控制

## 5. 亮点设计

- **玩家反馈：**

- **如何应用到我们的项目：**
- **优先级：** 🔴高 / 🟡中 / 🟢低

### 可借鉴 2：[名称]
- **原设计：**
- **如何应用：**
- **优先级：**

### 可借鉴 3：[名称]
- **原设计：**
- **如何应用：**
- **优先级：**

## 7. 不足/问题

- **设计缺陷：**
- **玩家抱怨点：**
- **如何避免：**

### 问题 2：[名称]
- **设计缺陷：**
- **玩家抱怨点：**
- **如何避免：**

## 8. 总结

- **学习价值评分：** ⭐⭐⭐⭐⭐（1-5 星）

- **拆解人：** 咔啦米
