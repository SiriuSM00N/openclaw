## 2. 核心循环分析

### 2.1 单局流程

```
[冥王宫起点] 
    ↓
[探索房间 → 战斗 → 奖励选择] × N 层
    ↓
[Boss 战]
    ↓
[死亡返回冥王宫 / 通关]
    ↓
[冥王宫叙事 + 局外成长]
    ↓
[新一轮逃离]
```

### 2.2 局外成长

**永久解锁内容：**
- 新武器（6 大类，每类 4 变种）
- 镜像之力（永久增益）
- 契约惩罚（难度调节）
- 新剧情/对话

**解锁资源：**
- 黑暗（基础货币）
- 宝石（高级货币）
- 钥匙（解锁武器/功能）
- 钻石（稀有升级）

### 2.3 循环驱动力

**玩家为什么再来一局？**

1. **叙事驱动** — 每次死亡推进剧情，想看到后续
2. **Build 多样性** — 不同祝福组合带来全新体验
3. **成长感** — 局外永久成长，即使失败也有收获
4. **挑战自我** — 热度系统提供无限难度上限
5. **收集欲** — 全武器/全祝福/全成就收集

**随机性来源：**
- 房间布局
- 敌人组合
- 奖励选择（三选一）
- 祝福池

## 3. 系统设计

### 3.1 战斗系统

**核心战斗机制：**
- 轻攻击/重攻击/特殊攻击/投弹
- 冲刺（无敌帧）
- 神力技能（冷却制大招）

**武器设计：**
- 6 大类：剑、矛、盾、弓、拳套、炮
- 每类 4 种"形态"（不同攻击模式）
- 武器决定基础攻击模组

**祝福系统（核心）：**
- 12 奥林匹斯神，每神提供不同增益
- 祝福分等级：普通 → 史诗 → 英雄
- 双神祝福（稀有）
- 传奇祝福（极稀有）

**敌人设计：**
- 小怪：骷髅、士兵、法师等
- 精英：高血量 + 特殊能力
- Boss：塔纳托斯、学习姐妹、最终 Boss

### 3.2 成长系统

**局内成长：**
- 祝福选择（核心 Build）
- 血量上限提升
- 金币收集（用于房间购买）
- 临时增益（食物、金币泉等）

**局外成长：**
- 武器解锁与升级
- 镜像之力（永久属性）
- 剧情解锁
- 音乐/画廊收集

### 3.3 经济系统

**货币类型：**

| 货币 | 用途 | 获取途径 |
|------|------|---------|
| 黑暗 | 购买镜像之力 | 击杀敌人、开启宝箱 |
| 宝石 | 购买高级物品 | 完成悬赏、首次通关 |
| 钥匙 | 解锁武器/功能 | Boss 掉落、任务奖励 |
| 钻石 | 稀有升级 | 采矿、特殊奖励 |
| 蜜露 | 提升好感度 | 首次遇见 NPC、特殊房间 |

**经济循环：**
```
战斗 → 获取资源 → 局外升级 → 更强战斗力 → 更深地牢 → 更多资源
```

### 3.4 关卡系统

**关卡结构：** 线性分支
- 4 大区域：塔耳塔洛斯 → 水仙花平原 → 至福乐土 → 斯堤克斯神庙
- 每层多房间，选择路径
- Boss 层固定

**房间类型：**
- 战斗房（必须清理）
- 奖励房（三选一祝福）
- 商店房
- 恢复房
- 特殊事件房

**难度递进：**
- 区域 1 → 4，敌人强度递增
- 热度系统可调节难度

### 3.5 叙事系统

**叙事方式：** 碎片化 + 死亡循环叙事

**创新点：**
- 死亡不是失败，而是叙事推进
- 每次返回冥王宫有新对话
- NPC 记得你之前的尝试
- 多周目解锁隐藏剧情

**角色塑造：**
- 希腊诸神人格化（宙斯花心、波塞冬粗鲁等）
- 家庭关系戏剧化（冥王父子矛盾）
- 配角有完整故事线

## 4. 数值分析

### 4.1 关键数值公式

**伤害计算（简化）：**
```
最终伤害 = 武器基础伤害 × (1 + 祝福加成%) × (1 + 镜像之力%) × 暴击系数
```

**示例：**
- 剑基础伤害：100
- 宙斯祝福 +50%
- 镜像之力 +20%
- 最终伤害 = 100 × 1.5 × 1.2 = 180

### 4.2 数值平衡

**职业平衡：**
- 各武器有不同攻速/伤害/射程
- 没有绝对最强，只有最适合 Build

**祝福平衡：**
- 稀有度决定强度上限
- 不同神祝福有协同/冲突

### 4.3 经济数值

**产出/消耗比：**
- 首次通关约需 10-15 小时
- 全解锁需 50-80 小时
- 资源产出随进度递增

## 5. 亮点设计

### 亮点 1：死亡即叙事

**设计描述：**  
传统 Roguelike 中死亡是惩罚，Hades 中死亡是叙事推进。每次返回冥王宫，NPC 会讨论你刚才的尝试，剧情会推进。

**为什么有效：**
- 降低死亡挫败感
- 给玩家"再来一局"的理由
- 叙事与玩法完美融合

**玩家反馈：**
> "第一次觉得死亡不是失败，而是想看接下来会发生什么"

### 亮点 2：祝福 Build 多样性

**设计描述：**  
12 位奥林匹斯神，每位提供 3-4 种祝福，加上武器 24 种变种，理论上有数千种 Build 组合。

**为什么有效：**
- 每局体验不同
- 鼓励尝试新组合
- 高重玩价值

### 亮点 3：热度系统

**设计描述：**  
通关后解锁"惩罚契约"，可添加各种难度修饰符（敌人更强、奖励更好），每个修饰符增加"热度"值。

**为什么有效：**
- 无限难度上限
- 玩家自定义挑战
- 高热度有高奖励

## 6. 可借鉴点

### 可借鉴 1：死亡循环叙事 🔴 高优先级

**原设计：** 死亡推进剧情，NPC 记得每次尝试

**如何应用到我们的项目：**
- 设计"轮回"叙事框架
- 每次失败解锁新对话/线索
- 让失败成为游戏体验的一部分

**适用场景：** Roguelike、叙事驱动游戏

### 可借鉴 2：祝福三选一机制 🟡 中优先级

**原设计：** 每层奖励房三选一祝福，构建独特 Build

**如何应用：**
- 设计我们的"三选一"成长系统
- 确保每个选项都有价值
- 选项之间有协同/冲突

**适用场景：** 任何 Roguelike 成长系统

### 可借鉴 3：热度难度系统 🟡 中优先级

**原设计：** 玩家自选难度修饰符，累积热度值

**如何应用：**
- 设计可叠加的难度选项
- 高难度有高奖励
- 让玩家自定义挑战

**适用场景：** 需要高重玩价值的游戏

## 7. 不足/问题

### 问题 1：后期内容不足

**设计缺陷：**  
通关后主要玩法是刷高热度，缺少新内容

**玩家抱怨点：**
- "通关后就没事做了"
- "高热度只是数值提升，没有新机制"

**如何避免：**
- 设计更多终局内容
- 添加新模式/新区域 DLC

### 问题 2：部分祝福过强

**设计缺陷：**  
某些祝福组合过于强大，降低挑战性

**玩家抱怨点：**
- "宙斯连锁闪电太强了"
- "有些 Build 无敌"

**如何避免：**
- 更好的数值平衡
- 添加动态难度调整
